# Tico source (Illustrator)

This folder is reserved for true Adobe Illustrator masters (`.AI`), `.EPS`, and print `.PDF` for the mascot **Tico**.

## Current state

No `.AI` file is committed. The Git vector masters are the SVG files under
`../01-vector/`.

## Export when Illustrator is available

1. Open the matching SVG from `../01-vector/poses/` or `../01-vector/stickers/` in Adobe Illustrator.
2. Save As `tico-mascot.ai` (and optional pose-specific `.AI` files).
3. Export `.EPS` / print `.PDF` if needed.
4. Commit only real exported binaries — never empty placeholders.
