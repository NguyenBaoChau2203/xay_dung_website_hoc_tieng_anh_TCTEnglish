# Logo usage

## Preferred lockups

| Context | Use |
| --- | --- |
| Learner header / wide chrome | Horizontal color |
| Narrow / stacked marketing | Vertical color |
| Favicon, app icon, avatar mark | **Icon only** (logo mark with stair + yellow spark) |
| Extreme small text fallback | Wordmark `TCT` (board variant) |

Site favicon must use the **logo icon**, not the Tico head crop.

## Clear space

Keep empty margin around the lockup at least equal to the height of the letter **T** in the wordmark (or ~20% of the icon height for icon-only).

## Minimum size

- Icon: not below 16px CSS / 32px PNG favicon export
- Horizontal wordmark: keep “English” legible; prefer icon-only under ~120px total width

## Do not

- Stretch or skew
- Recolor freely outside approved variants (`color`, `black`, `white`)
- Add drop shadows / 3D / extra gradients not on the board
- Place the black lockup on dark grounds or the white lockup on light grounds
- Replace the header logo with Tico

## Variants not on the board

Grayscale and JPG-on-white Office packs are **not** supplied in v0.1.
