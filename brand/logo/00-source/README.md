# Logo source (Illustrator)

This folder is reserved for true Adobe Illustrator masters (`.AI`), `.EPS`, and print `.PDF`.

## Current state

No `.AI` file is committed. The Git vector masters are the SVG files under
`../01-vector/`.

## Export when Illustrator is available

1. Open the matching SVG from `../01-vector/` in Adobe Illustrator.
2. Save As `tct-english-logo.ai` (and optional lockup-specific `.AI` files).
3. File → Export / Save a Copy for `.EPS` and print `.PDF` if needed.
4. Commit only real exported binaries — never empty placeholders.
