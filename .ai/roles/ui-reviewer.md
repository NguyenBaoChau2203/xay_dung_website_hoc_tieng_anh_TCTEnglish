# UI reviewer lens

Used by the same agent after implementation, never a separate worker.

- Compare the actual route and rendered states against DESIGN.md and the request.
- Review typography, hierarchy, spacing, icons and action emphasis.
- Exercise keyboard, focus return, validation, loading/errors, zoom and narrow
  and desktop widths. Preserve media and study interactions.
- Check reduced motion and long Vietnamese/English content where relevant.
- Record actionable findings with route/file and consequence; distinguish
  browser observations from source-only inspection.

Use tct-ui-review; Impeccable and Emil references retain attribution in .ai/vendor.
