TCT Design System — Component gallery

Mọi mẫu bên dưới dùng CSS thật của ứng dụng. Mở rộng/thu hẹp cửa sổ (1440 / 768 / 390px) hoặc phóng to 200% để xem hành vi responsive; nút ☰ dùng layout.js thật.

Nội dung tổng hợp (synthetic): form không gửi dữ liệu, không gọi API AI/media, không có dữ liệu thật.

--tct-text-xlTiêu đề thẻ — Card title
--tct-text-lgVăn bản dẫn — Lead paragraph
--tct-text-baseNội dung chính — Body text, ăn, ơ, ư, ạ, ệ, ỗ, ử, ữ
--tct-text-smPhụ đề, nhãn bảng — Secondary text

Buttons

Dùng Bootstrap .btn bên trong .tct-theme. Nút thao tác là <button>, điều hướng là <a>. Nút chỉ có icon cần aria-label và vùng bấm ≥ 44px.
