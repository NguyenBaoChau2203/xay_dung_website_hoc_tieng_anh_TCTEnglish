# RESPONSIVE_GUIDELINES — Authentication

Date: 2026-11-20  
Updated: 2026-11-20 (full-screen campus)  
Related: [ORGANIC_SHAPE_DIRECTION.md](ORGANIC_SHAPE_DIRECTION.md)

## Desktop 1440 / Laptop 1280

- Campus `cover` on `body` — one continuous scene  
- Left stage: brand + mascot + edu icons (sticky, centered)  
- Right: transparent; white `.auth-card` only  
- No dual backgrounds; no horizontal scroll  

## Tablet 768

- Smaller mascot and icon set  
- Card remains readable; icons may hide secondary tiles (ABC / dictionary)  
- Campus still full-bleed  

## Mobile 390 / 360

- Campus still full-bleed (`background-attachment: scroll`)  
- Form first priority  
- Compact mascot above or behind card area; hide most edu icons (keep ≤2 or none)  
- No decorative layer over inputs  
- Touch targets ≥44px  

## Overlay

Prefer opaque white card for contrast. Use only a *light* local veil under the card if QA fails contrast — never a full right-column paint.
