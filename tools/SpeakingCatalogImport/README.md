# Exact Speaking catalog correction (local only)

Read the current owner prompt and execution ledger before operating. No startup
job, schema/config edit, paid AI request, commit or release is part of this tool.
Latest owner instruction authorizes `ImportLocalTest` now, before manual QA:
it imports full acquired transcripts into the local catalog for owner testing.
It is loopback/dev-database-only at the CLI entry, retains pending QA in ignored
receipts and never creates synthetic review evidence. `Publish` still enforces
the strict quality proof for a later reviewed content milestone. Neither action
deploys code/data to staging or production.
The owner subsequently authorized same-level replacement of unavailable videos;
`replace.mjs` verifies captions and complete media before changing the target
selection. Original90 Listening roots/withdrawal keys remain unchanged. Every
replacement is an explicit manifest decision, never a level relabeling.

```powershell
# Canonical source acquisition; source text is untrusted reference data.
node tools/SpeakingCatalogImport/captions.mjs
node tools/SpeakingCatalogImport/media.mjs --pilot
# Continue only sources that have not already failed; never loop on HTTP403/429.
node tools/SpeakingCatalogImport/media.mjs --resume-untried

# Explicit selected IDs only; verified local audio/model hashes are required.
node tools/SpeakingCatalogImport/align.mjs --id=F5QyH36MnVo
node tools/SpeakingCatalogImport/collect-alignment.mjs --id=F5QyH36MnVo
# Experimental context variant retains older candidates for comparison.
node tools/SpeakingCatalogImport/align.mjs --id=F5QyH36MnVo --group=10 --context=1
node tools/SpeakingCatalogImport/collect-alignment.mjs --id=F5QyH36MnVo --group=10 --context=1
node tools/SpeakingCatalogImport/checkpoint.mjs

pwsh -NoProfile -File scripts/speaking-catalog.ps1 -Action Status
pwsh -NoProfile -File scripts/speaking-catalog.ps1 -Action Stage -SkipBuild
pwsh -NoProfile -File scripts/speaking-catalog.ps1 -Action ImportLocalTest -SkipBuild
# Snapshot captures once, thereafter compares every original row.
pwsh -NoProfile -File scripts/speaking-catalog.ps1 -Action Snapshot -SkipBuild
# Retire is repeat-safe; emits canonical next versions only where required.
pwsh -NoProfile -File scripts/speaking-catalog.ps1 -Action Retire -SkipBuild
```

`ImportLocalTest` reads the90 staged drafts, verifies complete source text plus
caption/media hashes, retains genuine source overlaps and bounds only source
caption ends that exceed the measured media file. It falls back to original
ordered source captions where an experimental aligner reverses adjacent cues.
These choices are explicit in each ignored local-test receipt, with QA=false.
The full video and transcript rows are transactionally usable by the existing
Speaking practice UI. The source topic is retained as provenance; reviewed
`CatalogTopic` supplies broad subject categories for learner discovery. New
Speaking packages are exported canonically after each successful aggregate.

`Publish` requires a complete `ReadySpeakingCatalogItem` per selected video in
ignored `ready/<exact-id>.json`. It preflights all90, or the six-level `-Pilot`,
before writing any public destination. Never fabricate these quality files or
copy a synthetic test proof. Source/media hashes must match acquired files;
full source-duration coverage, good region-specific token/timing/playback
evidence and zero unresolved flags are mandatory. Caption/word timestamps alone
do not establish whole-speech coverage. No ready files were generated by the
initial acquisition/alignment workflow.

`collect-alignment.mjs` produces **candidates** with original audio offsets,
explicit overlap/unknown-word flags and quality=false. It never clips/guesses
final cue times to force validation. Real repeated teaching text is retained.
Overlapping padded windows can misalign adjacent utterances; this must be fixed
or reviewed before any candidate is accepted. Coverage and playback review are
still required for every video. The current pipeline has no paid-ASR adapter:
its publication branch rejects gpt-transcribe receipts until an approved,
budgeted acquisition/receipt adapter is implemented and verified.

`cost-ledger.mjs` is an offline accounting primitive with synthetic tests. It
requires explicit approval, reserves the worst case before a request, reuses
successful chunk receipts, blocks automatic retry after an unknown/interrupted
POST, and enforces the ceiling including overlap. It contains no key or HTTP
client and is not an approved/live ASR adapter. No real approval ledger exists.

Audio acquisition caches and verifies each complete media hash/duration. An
isolated HTTP403 is retained by exact ID and is not retried by `--resume-untried`.
That mode tries each remaining URL once, with a pause after403; HTTP429 or three
consecutive403 responses stop the entire run. Other modes stop on the first403.
A failed acquisition exits2 so partial availability is not reported as success.

CTC experimental alignment:

```powershell
pwsh -NoProfile -File scripts/align-speaking-catalog.ps1 -Job F5QyH36MnVo-g10c1
```

The pinned Docker image already contains torch/torchaudio2.8.0. Its native CTC
extension is absent, so `ctc_alignment.py` implements the supplied-token CTC
Viterbi path directly, with synthetic tests. Bounded neural inputs retain
original measured frame offsets. Prefix/suffix wildcard context prevents
neighboring speech from stretching the last supplied word; it does not create
new words or prove full speech coverage. No greedy/beam transcript decoding is
performed. Confidence is **not** manually measured token accuracy.

Official TorchAudio weights are locally cached on D at
`torch-cache/hub/checkpoints/wav2vec2_fairseq_base_ls960_asr_ls960.pth`, SHA256
`488fd4f16de84438ffc945334278c1b9fb9b7159a806c1080b16111a958c945d`.
The tool fails before inference if they are absent or differ. Provenance:
[official model/license (MIT)](https://docs.pytorch.org/audio/2.8/generated/torchaudio.pipelines.WAV2VEC2_ASR_BASE_960H.html),
[forced-alignment method](https://docs.pytorch.org/audio/2.8/tutorials/ctc_forced_alignment_api_tutorial.html).
TorchAudio documents deprecation of its optional extension in2.8; this tool is
pinned to the observed runtime and does not depend on that missing extension.
CTC output remains a quality=false candidate. Ambiguous numeric readings,
non-English script, missing tokens, low confidence and overlap are explicit
flags; source text is preserved. Per-window caches include PCM, supplied text,
model and algorithm hashes. Different algorithms produce different cache keys.

Native Stage accepts complete text-preserving CTC candidates preferentially,
checks source/media fingerprints and emits immutable hashed drafts. It does
not copy drafts to `ready/` or populate coverage/playback/accuracy evidence.
