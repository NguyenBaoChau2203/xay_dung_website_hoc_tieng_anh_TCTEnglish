# Hero Props — Prop Style Sheet (Soft 3D Learning Atmosphere)

Decorative only. Not Tico/phone modeling.

## Direction
Premium minimal 3D studio + soft learning world.
Less decoration, clearer hierarchy: copy/CTA → phone → Tico → props → atmosphere.

## Material
- Soft clay / polished plastic
- Rounded forms, mild specular highlight top-left
- Soft contact shadow under each prop
- No emoji, no flat 2D icons

## Light
- Key: upper-left, cool studio white-blue
- Ambient ice glow behind phone + Tico only (subtle)
- Accent yellow `#FFD84D` sparingly on book edge
- No purple/magenta, no strong radial wash

## Allowed props (only)
| Prop | CSS size | Placement intent |
| --- | --- | --- |
| open-book | ~76×60 | lower-left of stage cluster |
| headphones | ~68×68 | upper-right near Tico |
| vocab-card (+ optional twin) | ~54×66 | mid-right of stage, clustered with chips |

## Vocabulary chips
LEARN / SPEAK / LISTEN only — small white cards, clustered near flashcard prop, not scattered.

## Removed from previous pass
Orbit rings, light trails/dots, ABC, graduation cap, speech bubbles, DISCOVER chip.
